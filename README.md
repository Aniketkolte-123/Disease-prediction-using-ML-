🩺 AI Healthcare Assistant – Disease Prediction Using Machine Learning
📌 Project Overview

The AI Healthcare Assistant is a Python-based desktop application that predicts possible diseases based on a patient's reported symptoms using Machine Learning algorithms. It features a modern graphical user interface (GUI) developed with Tkinter, allowing users to enter a patient name, select symptoms, and view disease predictions from three different machine learning models.

The application uses Decision Tree, Random Forest, and Gaussian Naive Bayes classifiers to analyze the selected symptoms and predict a possible disease. It also compares the predictions from all three models to identify whether they agree on the same result.

This project demonstrates how machine learning can be integrated into a desktop application to support symptom-based disease prediction for educational and research purposes.

✨ Features
🩺 Disease Prediction: Predicts possible diseases based on selected patient symptoms.
🧠 Three Machine Learning Models: Uses Decision Tree, Random Forest, and Gaussian Naive Bayes.
📊 Prediction Comparison: Displays the prediction from each model and checks whether the models agree.
🔍 Symptom Selection: Allows users to select up to five different symptoms from a dropdown menu.
👤 Patient Information: Accepts the patient's name before making a prediction.
🎨 Modern GUI: Provides a clean, user-friendly interface with a healthcare-themed design.
📱 Responsive Layout: Supports different screen sizes with a scrollable workspace.
🔄 Clear Functionality: Resets patient information, selected symptoms, and prediction results.
⚠️ Input Validation: Checks for missing patient information, missing symptoms, and duplicate symptom selections.
📁 Dataset Integration: Uses CSV datasets for training and testing data.
🛠️ Technologies Used
Programming Language: Python
GUI Development: Tkinter and ttk
Data Processing: Pandas and NumPy
Machine Learning: Scikit-learn
Dataset Format: CSV
🤖 Machine Learning Algorithms
Decision Tree Classifier: Predicts a disease by learning decision rules from symptom patterns.
Random Forest Classifier: Combines multiple decision trees to generate a prediction.
Gaussian Naive Bayes: Uses probability-based classification to predict a disease from the selected symptoms.

The application displays all three predictions and checks whether a majority of the models produce the same disease prediction.

🚀 How to Use
Launch the AI Healthcare Assistant application.
Enter the patient's name.
Select up to five symptoms from the available dropdown menus.
Click Predict Disease to generate predictions.
Review the results from Decision Tree, Random Forest, and Naive Bayes.
Check the model agreement message to see whether multiple models predict the same disease.
Click Clear to reset the application and perform another prediction.
